# 德佟 YLF-280 标签打印机对接实操指南 (Uni-app)

> 💡 **核心注意点**：德佟官方的 `LPAPI` 驱动是安卓/iOS的原生驱动。**必须在 HBuilderX 打包为真机 App（基座）后才可调用**。当前的 H5 网页预览只能走浏览器的 `window.print()`。

若您要在 App 内部一键蓝牙喷打，请严格按照以下 **SOP（标准作业程序）** 进行：

---

### 第一步：云端绑定并下载插件
1. 打开 **DCloud 插件市场**：[ext.dcloud.net.cn](https://ext.dcloud.net.cn/)
2. 在搜索框输入关键词：**`德佟`** 或 **`lpapi`**。
3. 推荐选用排名靠前且支持 `UTS` 的插件（如官方或大厂封装的通用蓝牙打印插件）。
4. 在插件详情页右侧，点击 **【试用】** 或者是 **【引入项目】**。
5. **非常关键**：系统会提示您选择您当前项目的 **AppID**（如果您是用 HBuilderX 创建的，请在 HBuilderX 打开项目的 `manifest.json` 查看）。

---

### 第二步：在 HBuilderX 中勾选配置
1. 用 **HBuilderX** 打开本项目：`/Users/long/Desktop/1230/AdUser/ITOM/mobile_app`
2. 双击打开根目录下的 **`manifest.json`** 配置文件。
3. 切换到 **【App原生插件配置】** 视图。
4. 点击 **【选择云端插件】**，勾选您刚才试用/下载的 **德佟打印插件**，并保存。

---

### 第三步：制作自定义调试基座 (核心中的核心)
*因为包含了底层 C++/Java 蓝牙驱动，官方的基座是不带这个驱动的，必须自己打个测试基座。*

1. 在 HBuilderX 顶部菜单栏，点击：**【运行】➔【运行到手机或模拟器】➔【制作自定义调试基座】**。
2. 按照步骤（如果没有证书可以选 DCloud 的公用测试证书）进行云打包。
3. 打包成功后，等待 3-5 分钟，控制台会提示打包完成。
4. 菜单栏点击：**【运行】➔【运行到手机或模拟器】➔【运行基座选择】➔【自定义调试基座】**（👈 必须勾选这个）。
5. 插上您的 Android 手机/iPhone，点击运行！

---

### 第四步：使用代码交付

我已经在项目中为您新建并封装了 **`src/utils/printer.ts`** 工具。

您只需要在项目里直接引入这个工具：
```typescript

    printByDetong(detail.value)

```

### ⚠️ 常见踩坑排雷
1. **找不到设备**：手机的**蓝牙开关**和**定位开关(GPS)** 必须同时打开，否则蓝牙搜寻不到任何设备。
2. **首次连接配对**：通常连接时配对码是 `0000` 或 `1234`（以设备说明书为准）。
3. **打印没反应**：德佟的 API 必须完全闭合：`startJob()` ➔ `.draw()` ➔ `.commitJob()`，缺一不可。
